# Axie Team Builder

Pick any 3 Axies, see the team total in pesos and every battle card, then send the seller your team.

- Site: https://makoymakoy121706.github.io/axie-team-builder/
- Wallet sync: `.github/workflows/sync.yml` runs `scripts/sync.py` every 15 minutes.
- Prices: `data/prices.json` (edit from the site with the Seller link, then commit on GitHub).
